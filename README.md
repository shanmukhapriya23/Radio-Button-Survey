# Radio Button Survey App

A lightweight, native Android application built with Kotlin that demonstrates how to implement interactive survey features using `RadioGroup` and `RadioButton` components.

## Features

- **Interactive Selection**: Users can select from a set of single-choice radio button options.
- **Dynamic Result Display**: Updates the screen with the selected response upon submission.
- **Selection Validation**: Prompts a Toast notification if the user attempts to submit without making a selection.
- **Clean UI**: Built using a simple `LinearLayout` for quick performance and smooth usability.

## Tech Stack & Tools

- **Language**: Kotlin
- **IDE**: Android Studio
- **UI Framework**: XML Layouts (`LinearLayout`, `RadioGroup`, `RadioButton`, `Button`, `TextView`)
- **Minimum SDK**: API 24 (Android 7.0 Nougat) or higher
